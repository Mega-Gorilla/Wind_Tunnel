# 小型風洞の測定機能・規格・UI調査

調査日: 2026-10-18 / 対象: Wind_Tunnel、Raspberry Pi 3B + Pico Carrier RevE

[2026年10月19日の開発優先順位](FEATURE_ROADMAP_2026-10-19.md): 固定板の再設計を保留し、市販6社7系列と現行実装の差から、先に開発する機能・受入条件を整理。CFDの最新評価は[再評価報告](../../tests/cfd/2026-10-19_fixed_plate_refined/REPORT.md)を参照。

## 結論

次の開発は、**測定条件・校正を管理する機能 → 定常収録 → 格子分布測定 → 回転数／風速一定制御**の順を推奨する。市販機の機能をすべて揃えるより、まず「どこで、何を、どの補正で測った値か」をUIと保存データから追跡できることが重要である。

現在のSDP810・BME280・INA260・Tachは、低速域の準定常測定に適した構成である。ただし、差圧から校正済み風速への変換、断面平均流量、真の乱流強度、揚力・抗力は別の前提を必要とする。取得できている数値と、計算・校正・追加機器が必要な数値を混同しない。

この文書は**調査に基づく実装提案**であり、規格適合証明・完成済み仕様ではない。この調査では実機を運転せず、制御コード・ファームウェア・Fusion形状を変更していない。

- [ピトー管格子固定のCAD参照レビュー](pitot-fixture-review.md): merged model v49を読み取り専用で確認。

## 2. どの規格を、何のために参照するか

「風洞ならこの規格」という単一の規格はない。測定対象によって適用範囲が異なる。下表は公式公開ページの版・適用範囲の確認であり、有料本文の全条項を監査した結果ではない。

| 規格・指針 | 確認した版・対象 | 本機への適用判断 |
|---|---|---|
| [ISO 3966](https://www.iso.org/standard/86000.html) | **2025年版**。閉管路内の定常流をピトー静圧管の速度面積法で測る | 局所速度から断面流量を求める際の重要な参照。単に5×5を測れば準拠になるわけではない。プローブ・直管条件・点配置・不確かさ等を本文で確認する必要がある |
| [ISO 5801](https://www.iso.org/standard/56517.html) | 2017 + Amendment 1:2025。標準化した流路によるファン性能試験 | ファンそのものの風量・圧力特性を評価する場合。一般的な模型試験の規格ではない |
| [ANSI/AMCA 210-25 / ASHRAE 51-25](https://www.amca.org/assets/resources/public/pdf/Publications/amca-210-25-downloadable.pdf) | **2025年版**。ファンの空力性能試験 | 本機のPWM掃引を、そのまま規格準拠のP-Q曲線と呼ばない |
| [JIS B 8330:2000](https://webdesk.jsa.or.jp/books/W11M0090/index/?bunsyo_id=JIS+B+8330:2000) | 2024-10-21確認、送風機の試験・検査 | 日本語の送風機試験の参照。風洞内模型の揚抗力測定とは区分 |
| [ISO 17713-1:2007](https://www.iso.org/standard/31497.html) | 回転式の風速計の風洞試験。始動しきい値・距離定数・伝達特性等 | 校正する対象がカップ／プロペラ風速計の場合。PCファンのTach読取仕様を決める規格ではない |
| [ISO/IEC 17025:2017](https://www.iso.org/standard/66912.html) | 試験・校正機関の能力等 | 校正履歴・トレーサビリティ・記録管理の背景。UIを実装しただけで認定は得られない |
| [JCGM GUM](https://www.bipm.org/en/web/guest/publications/guides) | 不確かさの評価・表現。100:2008と関連ガイド、2026年追補も公開 | 誤差要因・補正・不確かさの根拠を保存。表示桁数を精度とみなさない |

ISO 3966の旧2020年版やAMCAの旧版だけを根拠に新規仕様を固定しない。規格準拠を要求する段階で最新版本文を取得し、適用条件チェックリストを別途作成する。

## 3. 測れるもの、計算できるもの、追加機器が要るもの

| 測定機能 | 原理・必要条件 | 現在の構成での扱い |
|---|---|---|
| 差圧・温湿度・気圧・ファン電気入力・RPM | SDP810、BME280、INA260、Tach | 生値表示・記録が基本。取付位置、鮮度、単位、PPR等を併記 |
| ピトー管位置の局所風速 | `U = Cv × sqrt(2 Δp / ρ)`。Δpは確認済みの全圧－静圧。Cvはプローブ校正係数 | 配管極性・ゼロ・密度・補正・校正範囲を確定してから有効化 |
| 断面平均風速・体積流量 | `Q ≈ Σ(Ui Ai)`、`Uarea = Q / ΣAi` | 座標付きトラバースと面積重みが必要。中心風速×断面積を無条件に使わない |
| 風速の空間均一性 | 断面内の複数点の時間平均を比較 | 格子点と評価領域を保存。最大偏差／空間CV等の定義を明記 |
| 低周波の時間安定性 | 固定点の平均・標準偏差・傾き | 約2 Hzで観測した変動として表示。乱流強度とは呼ばない |
| 乱流強度・スペクトル | `TI = rms(u') / Umean`。帯域・プローブ応答・サンプリングを規定 | 現構成では未対応。高速熱線等と取得系の検討が必要 |
| 模型前後の圧力差／損失 | 適切な上流・下流圧力タップ、必要に応じ基準動圧 | SDP1台では風速基準と別の差圧を同時に測れない。追加センサーまたは切替と整定が必要 |
| 揚力・抗力・モーメント、CL/CD | 荷重計、支持具、ゼロ／姿勢補正、基準面積・長さ・動圧 | 追加ハードが必要。INA電流から抗力を推定して代用しない |
| ファンP-Q／効率 | 原則、一定回転数で抵抗を変え、規定の圧力・流量・入力を測る | PWMと風速の対応試験とは別。INAはDC枝路入力であり軸動力・AC入力ではない |
| 煙・画像の可視化 | 撮影条件、模型、時刻、照明等を記録 | 初期は写真／動画へのイベントマーカー。画像だけで定量PIVを名乗らない |

静圧差と全圧損失は同じではない。断面積・速度が異なる場所の静圧差を、そのまま損失係数の分子に使わない。CL/CD・Cp等も基準面積や基準動圧の定義を保存する。

時間変動と空間分布を区別する考え方は、[Quinnほか、2017年の風洞評価論文](https://lentinklab.com/wp-content/uploads/2022/06/1510350318_2017-lentink-wind-tunnel-quinn.pdf)でも重要である。高速計測の値と2 Hzの統計量を同じ指標として比較しない。将来の乱流測定は[CTAのメーカー解説](https://www.dantecdynamics.com/solutions/fluid-mechanics/constant-temperature-anemometry-cta/)も参照する。

## 4. 既存実装と照合して見つかった重要事項

### 4.1 差圧が表示できても、まだ校正済み風速ではない

現行の[センサー取得](../../../Electronics/pico/firmware/wt_sensors.py)はSDP810に`0x3615`を送り、温度補償された差圧の平均化モードで取得している。[Pi側変換](../../../software/control/windtunnel/pico.py)は符号付き差圧を処理し、風速は未校正のため未提供としている。この扱いを維持し、負差圧を無条件に絶対値化しない。

Sensirionの説明では、差圧用途の出力に対し、現地気圧を使う補正 `Δp補正 = Δp出力 × 966 hPa / p現地` が示される。これはベルヌーイ式に入れる空気密度の補正とは別である。現在の変換にはこの係数がなく、今後の校正処理で検討する。経験的な校正係数へ既に吸収している場合は二重補正しない。[信号補正ガイド](https://sensirion.com/en/media/documents/FEAE3023/667EC183/DP_AN_Signal_Compensation_V1.0_1.pdf)

湿り空気密度には温度・現地絶対圧・水蒸気分圧を用いる。実装初期は出典と適用範囲を明記した湿り理想気体式を用い、高精度化時に[CIPM-2007](https://www.nist.gov/system/files/documents/calibrations/CIPM-2007.pdf)等を検討する。簡易式をCIPM準拠と呼ばない。気圧は天気予報の海面更正値ではない。

配管抵抗も評価対象となる。SDPは微小な流れを使う方式であり、細い／長いチューブやアダプターが差圧伝達に影響する。チューブ両側の内径・長さ・継手・フィルター・接続先をセットアップ情報として保存する。[配管等の設計ガイド](https://sensirion.com/de/media/documents/C3059EE6/667E9FD4/DP_AN_Engineering_Guide_V1.0.pdf)

### 4.2 1 m/s付近では差圧が非常に小さい

密度1.2 kg/m³、Cv=1とした説明用計算を示す。メーカーの±125 Pa品のゼロ点精度0.08 Paと読み値の3%を加えた仕様幅を用い、速度への一次近似感度だけを計算した。**校正証明付きの合成不確かさや本機の実測誤差ではない。** [SDP800データシート、表1](https://sensirion.com/file/datasheet_sdp800-d/)

| 風速 m/s | 動圧 Pa | センサー仕様幅の例 Pa | 速度への相対影響の近似 |
|---:|---:|---:|---:|
| 1 | 0.60 | 0.098 | 約8.2% |
| 2 | 2.40 | 0.152 | 約3.2% |
| 3 | 5.40 | 0.242 | 約2.2% |
| 5 | 15.00 | 0.530 | 約1.8% |

近似は `δU/U ≈ 0.5 δp/Δp`。ゼロ付近では非線形性が強く、この近似自体も不十分となる。平均化だけでゼロ点・スパン・配管・位置決めの系統誤差は消えない。UIには測定下限、未校正、逆極性、範囲外等を示し、負値や極小値を黙って0 m/sへ置換しない。

### 4.3 平均化モードと2 Hz収録を正確に表記する

データシートのsmart averagingは、読み取り間隔が長い場合も単純な全区間平均ではない。最初の25 ms以降は指数平均へ移る。したがって、0.5秒ごとに読んだSDP値を「直前0.5秒間の厳密な平均」とは説明できない。内部の高い更新率も、そのままアプリの測定帯域を意味しない。[SDPデータシート、5.2節](https://sensirion.com/file/datasheet_sdp800-d/)

フィルター設定、読取周期、欠落数、集計窓を記録する。風速変動・圧力変動・RPM窓計数は測定方式が異なるので、単一の「測定精度」表示にまとめない。

### 4.4 80×80 mmと断面積6,271.312 mm²は単純な矛盾とは限らない

完全な正方形なら6,400 mm²だが、Fusion v49の内壁には四隅の斜面と丸みがある。従来提示された6,271.312 mm²との差は、角部の形状による可能性がある。今回、正確な流路断面積の再計算までは実施していない。

実断面の面積・輪郭・測定断面位置を確定するまで、6,400へ自動変更しない。面積を6,271.312から6,400へ替えるだけで、同じ平均速度から求める流量は約2.05%増える。正方形仮定の5 m/sなら115.2 m³/hだが、旧面積なら112.88 m³/hとなる。格子の端部セルには輪郭で切り取った面積重みを使う。

## 5. 推奨する測定手順

以下は本プロジェクト向けの提案であり、特定規格の規定値ではない。

1. **準備**: 模型・プローブ・測定断面・支持具・配管・校正IDを選択。前回から変更した条件を確認。
2. **ゼロ確認**: 停止し、両ポートを適切に等圧にした状態で確認。流れが残る状態や静圧差が存在する状態をゼロとして学習しない。
3. **基準確認**: 使用範囲に対応した基準風速計との比較、または有効な校正記録を確認。工場仕様だけをトレーサブルなシステム校正として扱わない。
4. **運転・整定**: 出力を制限付きで変更。固定待ち時間だけでなく、一定窓の平均・標準偏差・傾きで安定判定。
5. **収録**: 有効サンプル数・収録時間・欠落数を示し、生値と補正後値を保存。時間切れや不安定を成功として扱わない。
6. **停止・確認**: 停止指令、Pico応答、RPM低下を区別。必要に応じ試験後のゼロドリフトを記録。

安定判定の初期案は10秒窓等で評価し、判定しきい値は無負荷試験と反復試験から決める。低速では相対変動率が発散しやすいため、絶対Pa幅・速度幅を併用する。所定の連続時間安定した後に、別の収録窓を始める。

校正には上昇・下降の複数点と繰り返しを含める。基準機器の有効期限・不確かさ・適用速度域を保存し、単なるPWM→風速の近似曲線と計測器の校正を分ける。[NISTの風速校正](https://www.nist.gov/pml/sensor-science/fluid-metrology/fluid-metrology-calibration-services-air-speed)は基準との比較と環境条件管理の参考になる。

### 格子測定と治具

公称80 mm断面の5×5セル中心は、壁から**8・24・40・56・72 mm**。3×3なら13.33・40・66.67 mmである。初期の分布把握に5×5、再現性が分かった後の簡易点検に3×3を推奨する。ただし、現治具は5×5の穴であり、3×3等分位置はその部分集合ではない。

UIには穴番号、横位置、高さ、流れ方向位置、測定済み／再測定／無効を表示する。中心点を途中で再測定して時間ドリフトと空間差を分離する。壁付近の勾配が大きい場合は追加点を設ける。欠測点を0で埋めず、全断面の流量と中央領域だけの均一性を別結果にする。

現在のFusionには5×5治具が存在するが、流路を横切る板が流れを変える可能性がある。CAD確認の寸法・固定案・限界は[別紙レビュー](pitot-fixture-review.md)を参照する。[NISTの壁面・閉塞影響解説](https://www.nist.gov/pml/sensor-science/fluid-metrology/wall-and-blockage-effects-air-speed-calibrations)も、小断面でプローブや支持物の影響を無視しない根拠になる。

**移動するピトー管を風速制御のフィードバック源にして、そのまま分布測定しない。** 測定点の速度差を制御器が打ち消してしまうためである。初期は一定PWMまたは検証済み一定RPMと中心点の再確認を使う。一定風速を保った分布測定には固定した別の基準センサーが必要となる。

25点×30秒だけでも750秒となる。現行の1試験300秒上限を自動延長するのではなく、格子測定を複数の有限試験に束ねるcampaignとして設計する。手動でプローブを移すときは停止・位置確認を基本とする。

## 6. モードを二つの軸に分ける

| 軸 | 選択肢 | 注意点 |
|---|---|---|
| 制御対象 | PWM / RPM / 局所基準風速 / 動圧 | RPM一定は風速一定ではない。動圧一定と風速一定も密度変化時に異なる |
| 実験手順 | 単一点定常 / 時間収録 / 段階掃引 / 格子トラバース / 校正 / 反復比較 / 迎角掃引 | センサーと治具の能力に応じ選択可能にする |

現行の[Recipe](../../../software/control/windtunnel/models.py)はPWMが制御モードであり、RPM・風速閉ループを実装済みと表示しない。

最初に提供したいモードは次の6つ。

- **ライブ監視**: 値、単位、取得元、鮮度、品質状態を確認。
- **ゼロ・校正**: 停止／等圧確認、基準比較、校正履歴と適用範囲。
- **定常点測定**: 安定判定後に指定時間を収録。
- **段階掃引**: 上昇・下降、ヒステリシス、RPM・差圧・電力を比較。
- **格子測定**: 穴番号と実座標を案内し、断面図へ結果を配置。
- **履歴・A/B比較**: 同じ位置・模型・環境補正条件の結果を重ねて比較。

力・迎角・多点圧力・真の乱流評価は将来拡張とする。無効な機能は0表示せず「必要機器未接続」「未校正」等の理由を示す。模型試験ではReynolds数も記録し、形だけ同じ縮尺模型から実機性能を直接推定しない。[NASA Reynolds数の説明](https://www.grc.nasa.gov/WWW/K-12/airplane/reynolds.html)

## 7. UI・API・保存形式への反映案

### 800×480タッチUI

画面構成は「運転」「実験」「結果」「設定」を主軸とし、緊急時に探さなくてよい停止操作と、USB・遠隔許可・異常状態を常時確認できる構成を推奨する。ソフト停止を安全認証された非常停止とは表記しない。

運転画面は次を区別する。

- 指令: PWM %、目標RPM、目標風速など、現在有効な制御量。
- 実測: SDP差圧、Tach RPM、BME環境、INA電源。センサー名と単位を明記。
- 計算: 校正済み局所風速、密度、断面平均／流量。未成立なら理由付きで未提供。
- 品質: 未校正、安定待ち、収録中、欠測、範囲外、停止未確認。

グラフは比較可能な量を同軸に重ねる。圧力Pa、RPM、電力Wを説明なしに同じ縦軸へ載せない。格子画面の左右・上下面・視線方向を治具の刻印と一致させる。市販の密集したPC画面を縮小せず、タッチ用の大きな操作領域と段階表示に再構成する。具体例は画像集（ローカル保管・公開版には未同梱）に掲載した。

### データとAPI

現行の遠隔モードON/OFF・許可IP・APIトークン方式は維持する。ONの有効期間は無期限という合意を維持しつつ、Picoの短い運転許可リース、有限試験上限、停止／異常時の取消は別の保護として残す。

以下は新設候補であり、利用できるエンドポイント一覧ではない。

| 提案 | 保存・応答したい内容 |
|---|---|
| `capabilities` | 利用可能なセンサー、制御量、校正済み範囲、未提供理由 |
| `measurement-setup` | CAD版、実断面、プローブ、配管、極性、模型、支持具、基準座標、格子定義 |
| `calibrations` | 校正ID、基準機器、日付、適用条件、係数、補正式の版、不確かさの根拠 |
| `campaigns` | 複数の有限run、格子位置、繰り返し、開始前後のゼロ確認、欠測 |
| `results` | 生値、補正値、集計法、品質、有効数、条件付き比較とエクスポート |

生値→単位変換→ゼロ／気圧等の補正→校正係数→派生量→集計の処理順を固定し、版を保存する。校正を変えても過去の記録を上書きせず、別解析版で再計算する。外部API利用者が自己申告で「校正済み」や保護解除を設定できる設計にはしない。

必須の保存項目は、run/campaign ID、Pico boot ID・seq・計測窓、Pi時刻、実際の指令とRPM、座標、温湿度・現地気圧、差圧生値・補正値、チューブ情報、校正ID、断面面積、収録周期・フィルター、欠落数・無効理由である。現行にない項目は追加提案として扱う。

## 8. 開発優先順位と受入条件

| 優先 | 作業 | 受入条件の例 |
|---|---|---|
| P0 | セットアップ・補正・校正情報と品質表示 | 極性違い・未校正・低差圧・欠測で偽の有効風速を返さない。生値から計算を再現できる |
| P1 | 安定判定、定常収録、5×5ガイド、履歴比較 | 座標と穴番号がCAD／現物に一致。未測定点を区別。面積重みの合計と断面積を検証 |
| P2 | RPM制御、校正範囲内の基準風速制御 | 飽和・到達不能・失速・センサー断で安全に停止。移動プローブを誤って基準に使わない |
| P3 | 力、多点圧力、自動トラバース、高速変動測定 | 追加機器の校正・帯域・同期・支持具影響を別途確認 |

まずは模擬データで単位・符号・ゼロ近傍・欠測・不安定・座標・停止をテストし、次に実機の校正と反復性を評価する。本資料の作成時点では、この追加機能の実装・実機受入試験は実施していない。

## 調査範囲と残件

メーカーの製品ページ／データシート、規格発行元、センサーメーカー資料、NIST、原著論文を優先した。公開UI画像は公開カタログの掲載例であり、市販ソフトのライセンス取得や実機操作は行っていない。

残件は、ピトー管の実物形状と全圧／静圧接続、実断面積、支持板の影響、基準風速計、校正範囲・許容不確かさの確定。規格適合が必要なら、適用規格の全文確認を別工程で行う。Fusionの読み取り結果はCAD根拠JSON（ローカル保管・公開版には未同梱）に保存した。
