# 公開前確認（2026-10-19）

## 目的と公開方針

公開GitHubリポジトリの作成前に、送信候補と初回履歴の個人情報・認証情報を点検する。公式配布の風洞CADは二次配布せず、[MyWindTunnel公式サイト](https://nagare-giken.jp/mywindtunnel/)から取得するよう案内する。

独自の回路・PCB・FW・UI/API、追加固定部品の単体CAD、図、測定結果、調査報告、CFDコード・設定は公開対象。公式風洞を含む結合CAD、変換した形状、詳細形状抽出データは対象外。第三者のダウンロード資料は出典から参照する。

## 実施した修正

- 初回コミットの作者・コミッターのメールをGitHubのnoreplyに変更。公開前の履歴を1つの初回コミットに整理し、元の履歴はローカル専用の復旧用データに保持する。
- 実ユーザー名を含むPCパス、実機IP・SSHユーザー、機器識別情報を公開文書から除去。個人情報を含む管理・移行ログはGit対象外とし、元ファイルは削除しない。
- 自動起動テンプレートのユーザー固定パスを廃止し、同じサービス起動コマンドを直接実行する形式へ変更。実機への配備・運転は行わない。
- 独自機構のSTEP 3件・STL 5件を公開。現行Rev Eの回路・基板・製造ファイルは維持する。
- 公開版に含まれない資料のリンクを整理。公式風洞の取得先、公開範囲、KiCadライブラリーの条件をREADMEと索引に反映する。
