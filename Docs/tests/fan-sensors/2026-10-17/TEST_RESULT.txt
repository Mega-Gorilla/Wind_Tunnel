Wind Tunnel 全センサー・ファン100%段階試験
実施日: 2026-10-17 (JST)

結論
SW1をONにした後、停止から20/40/60/80/100%へ段階的に運転し、最後に停止した。
全134サンプルでSDP810・BME280・INA260の読み取りが成功した。
Tachカウントは出力段階とともに増え、最終約5.016秒は0エッジだった。
試験後に停止専用ファームウェアへ戻し、GP16 LOW・指令0%を再確認した。
本結果は短時間の動作確認であり、風速校正・定常特性・連続運転保証ではない。

今回の正式な再試験
・記録開始: 16:17:36.341、記録終了: 16:18:47.117。
・運転順: 0% 5秒 → 20/40/60/80/100% 各10秒 → 0% 12秒。
・PWM: Pico GP16、25 kHz。百分率はソフトウェアの指令値。
・回転検出: Pico GP15、RP2040 PWM7 Bハードウェア立下りエッジカウンタ。
・各センサーを約0.5秒周期で順番に取得。同時刻の完全同時測定ではない。
・測定主体はPico。PiはUSBデータ収集とBME補償計算に使用した。
・今回、Pi GPIOでの計数やオシロスコープ波形測定は行っていない。

段階別結果
運転段階と最終停止は末尾10サンプル（約5秒）を集計。
回転数は合計エッジ数／実測時間から計算し、2 pulse/revを仮定した値。

80%       1931         205.3       12.0025       2.458       -12.942

停止         0           3.75      12.0413       0.050        -0.010

注意: 100%の末尾でも差圧が変化しており、各10秒では完全な定常状態を
保証できない。2337 rpmを本装置の最終最大回転数とは扱わない。
停止時の電流はゼロ補正していない。ファン内部回路の待機電流や
センサーのオフセットを分離していないため、原因は断定しない。

全134サンプルでの範囲
・INA260電圧: 11.9700～12.0425 V。
・INA260電流: 3.75～371.25 mA。100%末尾平均352.25 mA。
・INA260電力: 0.05～4.44 W。
・SDP810差圧: -20.400～+0.00417 Pa。符号・ゼロオフセットは未補正。
・BME280温度: 平均27.380 ℃、範囲27.366～27.392 ℃。
・BME280湿度: 平均35.567 %RH、範囲35.389～35.672 %RH。
・BME280気圧: 平均1023.545 hPa、範囲1023.475～1023.622 hPa。
  気圧は現地の絶対圧で、海面更正値ではない。
  温度は設置位置の測定値で、基板からの熱影響を別途評価していない。
・INA260はファン側配線の計測値。Pi等を含むシステム全体の消費電力ではない。

検証
・134/134サンプル取得、欠落・I2C読み取り例外・SDP CRC不一致なし。
・SDPフレームの3ワードCRCと圧力スケール240を再検証。
・BME280 ID 0x60、INA260 manufacturer 0x5449 / die 0x2270を確認。
・BME280工場校正係数を使った倍精度補償計算をPC側でも再計算。
・既存の補償計算ユニットテスト7件が成功。
・ソースSHA-256と取得スクリプトの一致を確認。
  fan_steps.py: 889f587aedb657c758145d0e49d767228fb78909d062ad375c3e8a7d4cd5ddb3
・初期停止の末尾約2秒: Tach 0。最終停止の末尾5.016067秒: Tach 0。
・試験終了後INA260設定0x6127を復元。BME280の元の設定も復元確認。
・RAM上の一時診断コードのみで試験。Picoの永続ファームウェアは変更しない。
・終了時にPicoをリセットし、0.1.0-commissioning / locked-stopへ復帰。
・16:22:08からの最終確認: 3回のI2Cスキャンすべてで0x25/0x40/0x77を検出。
  両I2CバスのSDA/SCLはアイドルHIGH。再起動の繰り返しなし。
  指令0%、GP16 LOW、fan_enabled=falseを再確認。
・Pi: throttled=0x0、CPU温度47.8℃（BME測定の空気温度とは別）。

安全設定と確認範囲
・3秒ウォッチドッグ、75秒の診断コード時間制限を設定。
・電圧10.8～13.2 V、電流600 mA超で即中止、450 mA超連続2回で中止、
  差圧絶対値100 Pa超、回転検出欠落等で中止する既存条件を維持した。
・この試験では中止条件は発生しなかった。故障注入や保護動作そのものの
  実証試験は行っていない。測定周期より短い電圧・電流スパイクは未評価。
・ファン公式仕様は12 V、0.35 A、400～2500 rpm。
  今回の100%電流は公称値付近だが、電流定格への厳密な適合や
  長時間運転の温度上昇までは確認していない。
  参照: https://www.arctic.de/media/6f/a5/ea/1753621678/Spec_Sheet_P14_Pro_PST_EN.pdf

残件

   今回の負差圧はそのまま保存。絶対値だけを取って風速に換算しない。
2. 各段階を十分に保持し、回転数・差圧が落ち着いた後の定常特性を調べる。
3. 必要に応じ独立した回転測定・PWM波形確認、圧力/風速校正を行う。
4. 本番用の連続計測・制御アプリは別作業。現時点の常駐FWは停止専用。
