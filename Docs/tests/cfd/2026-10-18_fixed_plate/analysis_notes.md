# ピトー管固定板のCFD解析条件

報告と比較図はDocsへ整理しました。以下の `geometry`、`cases`、`tools` とスクリプト名は、[計算用フォルダー](../../../../analysis/plate_cfd_20261018) を基準とするパスです。読み物は [結果報告](REPORT.md) を参照してください。

## 評価する対象

現行Fusionモデル `merged model v49` の流路輪郭と `Pitotube plate` を使い、同じ流量で固定板を入れた場合と入れない場合を比較する。元のCADは読み取り専用で扱い、形状変更は行わない。解析の目的は、固定板の影響を無視してよいかを設計段階で判断することであり、ピトー管や風洞の校正係数を決定することではない。

## 幾何形状と計算条件

| 項目 | 条件 |
|---|---|
| 流路 | CAD内壁輪郭を前後に延長した一定断面の管。外接80 × 80 mm |
| CAD断面積 | メッシュから算出した6,271.168 mm² |
| 固定板 | CADから取得した厚さ5 mmの開口格子 |
| 流路内の板投影面積 | 2,168.575 mm²。閉塞率34.580% |
| 原点 | 固定板上流面の断面中心。流れ方向をy、横をx、高さをzとする |
| 入口と出口 | 固定板上流面からy = −200 mm、+200 mm |
| 比較断面 | y = −100、−55.053、−20、+20、+100 mm |
| ピトー相当位置 | CADプローブ最上流外形を基準にy = −55.053 mm。実際の圧力孔位置は現物確認が必要 |
| 25点 | x、zとも−32、−16、0、16、32 mm。上段Eから下段A、左から1～5 |
| 空気 | 非圧縮。密度1.2 kg/m³、動粘度1.5 × 10⁻⁵ m²/sを仮定 |
| 入口 | 一様軸方向速度3 m/s。乱れ強さ1%、乱れ長さ5 mmを仮定 |
| 出口 | ゲージ圧0、速度勾配0 |
| 固体壁 | 滑りなし、滑らかな壁。印刷面の粗さは省略 |
| 解法 | OpenFOAM配布版v2606、simpleFoam、定常k–ω SST RANS |
| 壁面 | Spaldingの連続壁関数。管壁に3層。採用候補の修正ケースでは固定板への追加プリズム層なし |
| 基本セル | 粗い格子は約5 mm、細かい格子は約4 mm。板表面近傍は3段階細分化 |
| 保存する出力 | メッシュ品質、方程式残差、流量収支、入口静圧、25点の軸方向速度、断面サンプル |

固定板あり／なしの同じ解像度同士は入口のメッシュ面積も一致するため、同一流量で比較できる。解像度間では流路面積の離散化に僅かな差がある。速度の点比較には同じ `cellPoint` 空間補間を用いる。収束監視の `probes` のセル値とは区別する。

## 解釈上の制限

- 一定断面モデルであり、収縮胴、ディフューザー、ハニカム、ファンを含まない。入口境界層の発達条件も実機と一致するとは限らない。
- 壁際の公称約0.2 mmの隙間は十分に解像できない。生成メッシュの板投影面積をCADと比較し、形状離散化による閉塞増加を結果に併記する。
- プローブ本体、使用中の穴の閉塞、静圧孔、チューブ、模型を含まない。したがってピトー指示値の誤差そのものを算出したものではない。
- 定常RANSは渦の時間変動を解かない。反復中の揺れを実時間の乱流変動や乱れ強さとして扱わない。
- 2種類の格子の比較は感度確認であり、収束次数や保証された不確かさの算定ではない。
- 3 m/sでの結果を1～5 m/sの全域へ無条件に外挿しない。

固定板による必要静圧の増加と、ピトー差圧の偏りは異なる。ピトー管の差圧は全圧と静圧の差であるため、固定板の圧力損失をそのままセンサー差圧から引いて補正してはいけない。同じPWMでの風量減少も、今回の固定流量解析だけからは決定できない。

## 数値結果を採用するための確認

1. 標準メッシュ検査と生成時の品質検査を確認し、不良メッシュのケースを除外する。
2. 入口と出口の流量不一致、方程式残差、25点の速度と入口静圧の反復履歴を確認する。
3. 反復末尾の速度・圧力の変動幅と、大小の格子での差を数値結果に添える。安定しないケースから確定した補正値を出さない。
4. 風速計の校正に使う場合は、固定板あり／なしの実測比較と独立した基準風速計を追加する。

生成時と標準検査に合格した修正メッシュにも、拡張検査では非凸セルが残る。粗い格子で13,732セル、細かい格子で20,080セル。負体積や補間重み・行列式の不良ではないが、「すべての拡張検査に合格した」とは扱わない。局所メッシュ形状も予備解析の制約に含める。

反復収束は残差だけでなく対象量の安定も確認する。[NASAの反復収束解説](https://www.grc.nasa.gov/www/wind/valid/tutorial/iterconv.html)。格子の細分化による感度と実験に対する妥当性は別の確認である。[NASAの格子収束解説](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)。

## 実行環境

公式Windows配布版OpenFOAMを、この解析フォルダーの `tools/openfoam2606` に展開した。システム全体へのインストールや環境変数の恒久変更は行っていない。並列ランタイムは追加せず、同梱のシリアル用DLLを使う。FreeCADは導入していない。インストーラーと入力ファイルのSHA256は `provenance.json` に記録する。

既存Dockerの起動はOTelソケットエラーで失敗したため、Dockerを使った解析は行わなかった。Dockerの初期化・データ削除は実施していない。

## 出典と再現用ファイル

- [OpenFOAMのWindows版案内](https://www.openfoam.com/openfoam-mingw-cross-compilation)
- [SSTモデルと入口条件](https://doc.openfoam.com/2606/tools/processing/models/turbulence/ras/linear-evm/rtm/kOmegaSST/)
- [Spalding壁関数](https://doc.openfoam.com/2312/tools/processing/boundary-conditions/rtm/derived/wall/nutUSpaldingWallFunction/)
- [NISTの校正に対する閉塞と壁面の影響](https://www.nist.gov/pml/sensor-science/fluid-metrology/wall-and-blockage-effects-air-speed-calibrations)
- `geometry/fusion_geometry.json` と `geometry/geometry_summary.json`：CAD形状と断面積
- `build_cases.py`：メッシュと境界条件の生成。修正ケースでは `--plate-layers 0` を指定
- `run_foam.py`：専用環境での実行とログ保存
- `cases/*/system`、`cases/*/0`、`cases/*/constant`：実際の解析入力
- `cases/*/execution.jsonl`、`cases/*/log.*`：実行履歴と検査ログ
- `mesh_metrics.py`、`inspect_results.py`、`plot_results.py`：品質確認、数値抽出、比較図

最終結果の判断は、[結果報告](REPORT.md) の採用ケースと検証値に従う。未収束のため校正には採用しない。
