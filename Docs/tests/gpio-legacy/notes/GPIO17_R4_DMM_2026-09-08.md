# R4両端のテスター測定（ユーザー報告）

2026-09-08。直前の依頼順に、R4の3.3 V側=3.296 V、GPIO17側=2.702 Vとして解釈。ユーザー記載は「R4 3.296v / R4 2.702v」。Pi GNDを基準にDC電圧測定する依頼への回答であり、実機をこちらで独立検査した値ではない。テスターの機種・確度は不明。

継続条件：R3のファン側は開放、R4は公称10 kΩのプルアップ、発振器信号とファンTachは切り離し、CH1先端はGPIO17、GNDは共通として扱う。報告時に追加の接続変更は示されていない。

## 計算と解釈

- R4両端差：3.296 - 2.702 = 0.594 V。
- R4が実際に10 kΩで、測定中の状態が一定なら、R4を流れる電流は約59.4 µA。
- 同時刻ではないが、直前のオシロ表示約2.68 VとGPIO側テスター値との差は約0.022 V。確度が不明なため校正の妥当性を保証はしない。
- 電圧差をオシロの指示誤差だけでは説明できない。供給側には3.296 Vがあり、GPIO17側にかかる負荷・配線・測定器・GPIO入力などを切り分ける必要がある。
- 59.4 µAはR4の電流であり、GPIO入力だけの漏れ電流とは断定しない。オシロ、テスター、他の残存配線の負荷も含まれ得る。
- GPIO故障、R4不良、プルアップ抵抗の変更が必要とはまだ断定しない。

## 次の提案（未実施）

発振器・ファンTachを外したまま、オシロCH1先端のみをGPIO17ノードから外し、R4両端の対GND電圧をテスターで再測定する。R4やGPIO17への配線とGNDクリップは維持し、測定器負荷の影響を先に分離する。変更時の短絡を避けるためPiをシャットダウンし給電を切り、先端を外して再給電する。次に必要ならGPIO17接続自体を分離した試験を検討するが、今回未実施。
