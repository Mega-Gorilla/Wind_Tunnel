# GPIO17 内部プル無効化の前後比較（測定メモ）

2026-09-08 18:11–18:13 JST。ユーザーはGPIO17配線とオシロCH1を戻し、前段で提案した対照試験の実施を依頼した。正式PDFは全測定完了後とするため未更新。

## 条件と操作

- R4：公称10 kΩ、Pi 3.3 V → GPIO17（BCM17、物理11番）。R3のファン側は開放。
- オシロCH1先端はGPIO17、GNDはPi共通GND。発振器信号とファンTachは切り離した前提を維持。
- 変更前 `known_input_20260908_181152/`。内部プル状態は読み戻せないためAS_ISと記載し、プルダウンが読み取りで確認済みとはしない。
- 変更後 `known_input_20260908_181258/`。18:13:00 JSTに `pinctrl set 17 ip pn` を実行し終了コード0で完了。入力モードを維持して内部プルを無効化する操作。
- 両測定のboot_idは `b23a84fa-0a21-41aa-b947-8a12a19431ad` と一致。間に再起動なし。
- 変更後の試験でも、イベント要求はBias.AS_IS（設定済みの状態を維持）、デバウンス0。
- 発振器への通信なし、GPIO18・ファン制御・起動設定の変更なし。

## 結論と限界

同一配線・同一起動セッションで、内部プル無効化後に代表電圧が約0.54～0.56 V上昇した。先行のテスター分圧結果、公式の内部プルダウン仕様と合わせて、約2.7 VへのDC低下に内部プルダウンが関与していたことを強く支持する。GPIOの故障による漏れだけが原因と判断する根拠はない。

ただし、この前後比較では変更前から不要イベントが0件だった。過去の大量イベントを内部プル設定だけで説明できたわけではなく、実パルス計数とファンTach取得の正常性も未検証。R4の抵抗実値、入力パッドのヒステリシスなども未測定。

## 終了状態・次の手順

GPIO17は入力、実行時設定はpull-noneのまま。pinctrl表示は仕様上引き続き「--」で、設定読み戻しの保証ではない。GPIO18はoutput High、停止指令を維持。起動時設定は変更していないため、再起動または他ソフトのGPIO設定でこの条件が変わり得る。元のプル状態を直接読めないため、推測で復元する書込みは行っていない。

次は再起動せずGPIO17点の対GND電圧をテスターで確認。その後、正しいR3経由の既知パルス試験とファンTach試験を計画する。発振器の出力ONには改めて接続・電圧・出力許可を確認する。恒久化と正式PDFは未実施。
