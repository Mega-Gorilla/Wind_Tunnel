# 発振器信号線切り離し後のGPIO17対照測定

2026-09-08 16:49 JST。ユーザーは発振器を切り離し、オシロ先端がBCM GPIO17（物理11番）であることを明確に確認した。プルアップと共通GNDは残る前提で測定したが、残存配線・抵抗の接続を独立に検査してはいない。

測定フォルダー：`known_input_20260908_164905/`。

## 実施範囲

発振器には問い合わせだけを送り、設定変更・出力ON/OFFコマンドは送っていない（run_log.jsonのwriteレコードは0件）。開始・終了時とも両CH出力OFFを確認した。

PiはGPIO17 input、GPIO18 output High、ファン停止サービスactive。GPIO17へのエッジ要求だけを一時的に実施し、終了後は解放した。GPIO18、バイアス、入力パッド設定、恒久設定は変更していない。レポートPDFは更新していない。

## Pi：割り込みなしの直接レベル読み取り

GPLEV0をread-only mmapで読み取った。取得前後ともREN/FEN/HEN/LEN/AREN/AFENは無効。

- 時間：0.250007878 s。
- 読取：37,314回。
- High：37,140回、Low：174回。
- 連続標本間の論理変化：348回。

先行の発振器接続・出力OFF条件ではLow 305/36,853回だった。どちらもLowが混ざったが、不等間隔の短時間標本であり、回数の減少を統計的改善やノイズ量の減少とは解釈しない。

要求中のREN/FENは指定どおり。レベル検出・非同期エッジ検出は無効だった。両エッジ列は立上だけであり、正常な交互列ではない。表の処理時間と最初/最後のイベント時刻差は別の量である。

## OSC：GPIO17電圧

CH1・×1・DC・5 Vレンジ。各Pi試行に合わせて取得処理を動かし、25 kS/s・200 msを3本、100 MS/s・50 µsを16本ずつ、合計57本取得した。

- 代表電圧（High側中央値）：約2.68 V。
- 全標本の瞬時範囲：2.38-2.94 V。
- 1/2 Vの解析閾値で立上・立下とも0回。

取得処理は並行して動くが、波形は断続標本であり、Piの各イベントと同期していない。オシロの記録範囲外にある短時間変動を否定しない。High側中央値を3.3 V電源の実測値と混同しない。

## 解釈と次の測定

発振器信号線を切り離した条件でも、直接レベルのLow混入と過剰イベントが残った。ユーザー報告どおり信号線が切れている前提では、その信号線接続は異常再現の必須条件ではない。発振器以外の配線・プルアップ・接地・入力パッドやSoC側の問題はまだ分離できない。

次は、発振器とファンTachを切り離したまま、GPIO17を抵抗経由で既知DC Lowへ固定した対照を行う。既知High試験と、プルアップ／GNDの接続確認も必要。今回これらの配線変更・測定は行っていない。

終了時はGPIO17 input High、GPIO18 output High、WF1974 CH1/CH2 OFF。パスワードは対話入力のみでファイルに保存していない。
