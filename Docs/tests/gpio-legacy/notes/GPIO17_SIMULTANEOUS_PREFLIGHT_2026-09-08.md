# GPIO17同時測定の事前確認：出力ON前に中断

2026-09-08 19:15〜19:21 JST。現配線での測定についてユーザー許可あり。配線変更、ファン駆動、起動設定変更、入力パッド変更は実施していない。正式PDFは全測定後。

## 実施結果

- 実機：Raspberry Pi 3 Model B Plus Rev 1.3、カーネル6.18.34+rpt-rpi-v8、パッケージ1:6.18.34-1+rpt1。
- GPIO17：入力High、事前gpioinfoにconsumerなし。GPIO18：出力High、ファン停止サービスactive。
- Device Treeのsoc/rangesを読み、バス0x7e10002cからCPU物理0x3f10002cへの対応を検証。sudoによる/dev/memのO_RDONLY・PROT_READマップで1ワードのみ読取り。
- GPIO0〜27のPADS値は **0x1B**。HYST bit3=1でヒステリシス有効。SLEW bit4=1、DRIVE code3。共有設定への書込みなし。ヒステリシス無効という仮説は今回の読取り時点では支持されない。
- WF1974：対象機器IDと、両CH OFF、独立、High-Z、50 Hz矩形波、2.4 Vpp、offset +1.5 V、duty50%、連続、加算OFFを読出し確認。波形設定変更なし。
- 出力OFFの立上りイベント取得：約3.008秒、0件。開始／終了のGPIO17子IRQスナップショットも保存。
- 同時取得用オシロの最初の連続ブロック（25 kS/s、852点）で3.00〜3.42 Vを記録し、今回新設した保守的な瞬時最大値3.3 Vの条件を超えたため、**発振器ON前に中断**。
- 終了時にCH1 OFFを送信し、CH1／CH2とも0を読出し確認。ONコマンドは一度も送っていない。

## OFFのまま追加確認

発振器設定には触れず、オシロのみで連続20ブロックと従来の通常取得19記録を取得した。

通常取得は中央値約3.22〜3.24 V、全記録の最小〜最大2.98〜3.44 V、クリッピングなし、解析閾値1／2 Vを跨ぐエッジなし。連続モードだけでなく通常取得でも似た幅があり、単純に取得開始だけの現象とは判定できない。

重要：3.44 Vはオシロの標本値であり、校正誤差・ノイズ・実際の電圧変動を分離できていない。この値だけでPiが過電圧になっている、GPIOが故障したと断定しない。また、このHigh付近のばらつきだけで前回の過剰イベントを説明したわけではない。
