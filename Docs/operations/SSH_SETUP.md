# 実機接続情報の管理

Gitには実際のSSH接続メモ、ホスト鍵、パスワード、Wi-Fi設定を含めない。実機管理者から接続先とユーザー名を確認し、SSHホスト鍵の指紋を別経路で確認してから接続する。

```text
ssh <user>@<host>
```

この作業PCの既存接続メモは `Docs/operations/SSH_CONNECTION.md`、ホスト鍵は `.local/ssh/` に残るが、どちらもGit対象外。新しいPCでは自動的に取得できない。

既存管理スクリプトが要求する `WT_PI_PASSWORD` は、実行時だけ安全な方法で環境変数へ設定し、終了後に解除する。ソース、Issue、端末の共有ログに値を書かない。スクリプトによって参照するホスト鍵ファイルと環境依存が異なるため、実行前に対象を確認する。

開発とCIは模擬Picoで行える。実機への配備やファン試験は接続確認だけでは開始せず、作業範囲・配線・停止条件を確認してから実施する。
