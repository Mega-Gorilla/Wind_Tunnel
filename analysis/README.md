# CFDコードと公開範囲

独自の解析コード、ケース設定、数値集計、比較図は公開します。公式配布の風洞CADを再配布しないため、風洞本体のSTLや形状を記録したFusion出力は同梱しません。本体は[MyWindTunnel公式サイト](https://nagare-giken.jp/mywindtunnel/)から取得し、利用条件を確認したうえでローカルに配置・変換してください。

- [初回評価のコードと条件](plate_cfd_20261018/README.md)
- [形状再現改善・非定常・Linux比較](plate_cfd_20261019/README.md)
- [最新の報告書と結果](../Docs/tests/cfd/2026-10-19_fixed_plate_refined/REPORT.md)

コードが参照する形状、生成格子、途中の計算場、ログ、仮想環境、OpenFOAM本体はローカル保管です。cloneだけで再計算・途中再開できる状態ではありません。下位の履歴メモにある「保持」「保存」は実験時のローカル作業環境を指します。

結果は未収束の予備解析で、実測風速の校正には使えません。公開準備では測定値・解析結果を書き換えていません。
